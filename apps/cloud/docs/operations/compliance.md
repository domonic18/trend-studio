# 合规与公测检查清单

版本：v0.2（2026-11-01）

面向公测放行的数据与合规基线：数据清单、保留与删除、同意、访问控制、日志脱敏、密钥与第三方处理、事件响应。实现缺口在 §9 明确列出，未完成项不得在对外材料中宣称已具备。

## 1. 原则

- 数据最小化：只收集课程服务必需字段；学员语音音频与转写只在内存中转发，不落盘。
- 默认不采集指标：`POST /v1/events` 需要用户显式同意，可随时撤回。
- 内容先审后发：生成内容只写 `draft`，人工发布后才对学员可见。
- 密钥最小暴露：平台密钥只放环境变量；模型密钥以 AES-256-GCM 密文存库，不进浏览器、插件、日志或响应。
- 门户自助注册只创建 `student`；门户会话与后台会话按 `scope` 隔离，学员令牌不能访问 `/v1/admin/*`。
- AI 用量只记数字、模型标识与错误码，不落 prompt、正文或用户身份。
- 不接第三方分析 SDK，不做跨站追踪，不向广告平台共享数据。

## 2. 数据清单

| 类别 | 数据 | 位置 | 保留 | 第三方处理 |
|---|---|---|---|---|
| 账号 | 用户名、显示名、角色、状态、密码 scrypt 哈希（含门户自助注册的 `student`） | `users` | 账号存续期 | 无 |
| 会话 | 会话令牌哈希、过期时间、用户、作用域 `console/portal` | `sessions` | TTL（默认 12h） | 无 |
| 邀请码 | 邀请码哈希、使用状态 | `invites` | 兑换或过期 | 无 |
| 设备授权 | 设备 ID、设备码哈希、授权记录 | `device_codes`、`tokens` | 设备码 TTL（5min）、令牌 TTL | 无 |
| 令牌 | access/refresh 令牌哈希（不存明文） | `tokens` | access 15min、refresh 30 天 | 无 |
| 学习进度 | 知识点、观看秒数、完成状态 | `progress` | 账号存续期 | 无 |
| 指标同意 | 用户同意/撤回状态 | `events_consent` | 账号存续期 | 无 |
| 指标事件 | 白名单事件名、时间戳、课程/知识点标识（仅同意后） | `events` | 建议按季度归档/清理（未自动实现） | 无 |
| 播放会话 | 用户、设备、片段、过期时间 | `playback_sessions` | 到期即不可用；行保留待清理（未自动实现） | 无 |
| 课程内容 | 课程/章节/知识点/文章/片段；文章为安全 Markdown 子集 | `courses` 等 | 运营期；下架用 `archived` | embedding 供应商收到片段正文 |
| 建课素材 | 素材元数据、源视频、HLS、转写、生成草稿 | `media_assets`、`media_transcripts`、`content_generations`、`workspace/pipeline/` | 源视频默认保留（策略未冻结） | ASR 供应商收到音频块；LLM 供应商收到转写窗口 |
| 运行日志 | 请求方法、路径（去掉 query）、状态码、耗时、请求 ID | stdout（宿主收集） | 由宿主日志轮转决定，建议 ≥30 天 | 无 |
| 指标 | 请求计数、耗时直方图、管线任务状态（聚合） | `/metrics` | 由 Prometheus 保留策略决定 | 无 |
| AI 用量 | 任务键、provider/model 标识、token/音频秒数/字符数、耗时、状态与错误码；不含 prompt 与正文 | `ai_usage_events` | 未自动清理（见 §9） | 无（仅记录调用元数据） |
| AI 运行 | 任务/来源标识、状态、主备配置、步骤链与错误码 | `ai_runs`、`ai_run_steps` | 未自动清理（见 §9） | 无 |
| 模型配置 | 连接信息、价格、密钥密文（AES-256-GCM）、掩码 | `llm_configs` 等 | 配置存续期 | 无 |
| 备份 | 全库导出（含上述业务数据） | `workspace/backups/` | 默认 14 天 | 无 |

不记录：明文令牌、完整设备 ID（日志）、完整 `query`、完整播放地址、转写正文（日志）、源文件路径、provider 原始响应体。

第三方处理边界：

- 语音转写（MiniMax）：仅学员短语音（≤60s）与管线音频块；音频不落盘。
- 内容 LLM：仅管理端建课使用的转写窗口；生成结果进入 `content_generations` 草稿。
- embedding：已发布/待索引片段正文；用于检索向量。
- 以上均通过 HTTPS，密钥只在服务端；不把用户身份信息拼入请求。

## 3. 同意与撤回

- 指标上报默认关闭；`GET /v1/events/consent` 查询，`PUT /v1/events/consent` 开启/撤回。
- 撤回后不再接收事件；历史事件不自动删除（见 §9）。
- 学习进度不属于指标，不受同意开关影响，也不用于行为分析。

## 4. 访问控制

| 面 | 规则 |
|---|---|
| 学员接口 | Bearer + `x-device-id`；设备不匹配 `403`；令牌过期 `401` |
| 管理端接口 | 后台会话（operator/admin）；学员令牌不可访问 `/v1/admin/*` |
| 门户接口 | `scope=portal` 会话；只能操作本人资料与设备；公开接口仅发布清单与统计 |
| 管理端前端 | 令牌只存 `sessionStorage`，不使用 Cookie；关标签即失效 |
| 门户前端 | 令牌只存 `sessionStorage`；未登录访问个人中心跳转登录 |
| AI 后台接口 | 用量/运行/健康 operator 可读；任务绑定写仅 admin |
| 内容写操作 | 仅 operator/admin；发布必须显式调用 |
| 数据库 | 不对公网暴露；仅 Compose 内网 |
| 指标端点 | `Authorization: Bearer $METRICS_TOKEN` |

## 5. 日志与脱敏

- 全局日志脱敏：`authorization` 与 `x-device-id` 请求头；业务日志不打印令牌、密码、转写正文、provider 响应体。
- 请求日志只记路径（去掉 query）、状态码、耗时与请求 ID。
- 管线失败只暴露稳定 `error_code` 与静态文案；ffmpeg stderr 与 provider 响应仅内部日志且不含正文。
- 抽查方法见 [部署 Runbook §11](./deployment-runbook.md#11-视频管线运维)。

## 6. 密钥与凭据

- `METRICS_TOKEN`、`MEDIA_SIGNING_SECRET`、`POSTGRES_PASSWORD`、`CREDENTIAL_ENCRYPTION_KEY` 只放 `.env.prod`（600 权限）或密钥管理服务；ASR/LLM/embedding key 由 admin 在后台录入，以 AES-256-GCM 密文存库，接口与日志只出现掩码。
- 非 local 强制 HTTPS；生产拒绝本机地址；本地默认密钥在非 local 启动即失败。
- 轮换：媒体签名与指标令牌可直接替换后滚动重启；ASR/LLM key 在供应商侧轮换后在后台「模型配置」直接更新，无需重启；数据库密码变更需同步 `DATABASE_URL` 并重启；轮换 `CREDENTIAL_ENCRYPTION_KEY` 会使既有密文不可解密，必须先在后台重新录入全部模型密钥。
- 不提交 `.env`、证书、密钥、样片大文件；仓库只保留 `.example`。

## 7. 内容版权与人工审核

- 上传建课的源视频必须已取得课程使用授权；授权范围与保留期限由运营书面确认。
- 生成内容一律 `draft`；运营必须在管理端预览章节、知识点、置信度与待审原因后手动 `apply` 并 `publish`。
- 文章只接受安全 Markdown 子集；拒绝 HTML/脚本/事件属性。
- 下架用状态位（`archived`），不做物理删除，避免 `segmentId` 复用与引用失效。

## 8. 保留、备份与事件响应

- 备份默认每天 03:17，保留 14 天；恢复演练用 `scripts/restore-drill.sh` 导入独立演练库，不触碰业务库。
- 恢复演练至少每季度一次，并跑设备授权 → 检索 → 播放冒烟。
- 事件响应：
  1. 发现疑似泄露立即轮换 `MEDIA_SIGNING_SECRET`、`METRICS_TOKEN`、ASR/LLM key 与数据库密码。
  2. 保留宿主日志与 `/metrics` 快照，记录时间线与影响面。
  3. 通知运营与课程方；涉及个人信息时按适用法规在时限内告知。
  4. 修复后补回归测试与文档，复盘记录归档。

## 9. 已知缺口（公测前评估）

| 缺口 | 现状 | 建议 |
|---|---|---|
| 账号注销/数据删除 | 未实现；只能人工停用账号 | 公测前提供停用 + 数据删除流程（按用户清理进度、同意、事件、播放会话、门户会话；保留审计最小集） |
| 指标事件与播放会话清理 | 无自动清理任务 | 增加定期任务或运维脚本，明确保留天数 |
| AI 用量与运行记录清理 | 无自动清理任务 | 明确保留天数（建议与日志同为 ≥30 天），定期归档或删除；清理不影响课程内容 |
| 门户会话清理 | 依赖过期时间，行保留待清理 | 与会话清理任务一并处理 |
| 源视频保留策略 | 默认永久保留，未冻结 | 运营确认版权与重试窗口后设定保留期与清理任务 |
| 日志保留 | 依赖宿主轮转 | 在部署主机配置 logrotate/日志驱动保留 ≥30 天 |
| 数据导出 | 未实现 | 如用户提出，走人工导出并登记 |
| 多实例限流 | 单实例内存限流，配额按实例放大 | 扩多实例前换成共享存储（Redis/DB） |

以上缺口未关闭前，对外只描述已实现能力，不宣称“完整合规认证”。

## 一件工具，四个环节

学习趋势交易时，真正耗时的往往不是看视频，而是**找内容**和**确认自己没记错**。本站把课程内容组织成可检索、可回溯、可复习的结构，嵌进你日常使用的 dsh 客户端。

### 知识检索

用自然语言描述问题，例如「上升趋势回撤到哪里算有效支撑」，系统会在课程片段与知识点文章中检索相关内容。

- 结果按相关度排序，并给出处：来自哪门课、哪个知识点、哪一段视频。
- 检索只覆盖课程内容，不接入实时行情或外部预测。
- 回答中会标明内容不可信边界，避免把检索结果当成投资建议。

### 片段定位

每个引用都对应一个**代码块编号**或课程内链接：

- 在问答面板中点击 `seg-xxx` 代码块，直接跳转到对应视频秒数。
- 在 Web UI 中打开课程正文，点击引用链接同样可以定位。
- 起止时间以云端返回为准，手动改 URL 里的时间不会生效。

如果视频无法定位，请先确认服务端支持 HTTP Range 请求，并检查播放器是否加载了加密 HLS。

### 课程体系

按「课程 → 章节 → 知识点」组织的学习路径：

- 随时查看已学与未学内容，避免在长课程里迷路。
- 知识点文章提供结构化总结，适合快速复习。
- 学习进度保存在云端，换设备后登录同一账号即可继续。

### 伴学问答

问答面板的定位是**课程伴学**，不是通用聊天机器人：

- 能回答课程范围内的概念、方法与知识点解释。
- 不提供具体买卖点、仓位建议或收益承诺。
- 生成式推理在你的本地客户端完成，云端只负责检索与内容服务。

## 数据与边界

| 事项 | 处理方式 |
| --- | --- |
| 课程内容 | 云端存储与检索 |
| 账号与设备 | 云端存储，用于授权与进度同步 |
| 模型密钥 | 仅保存在本地客户端，云端不接触 |
| 推理请求 | 由本地客户端发起，直连你配置的模型服务 |
| 检索问题 | 仅用于本次检索，不作为训练数据 |

## 不适合用它做什么

- 代替你判断某只股票、某个品种现在能不能买。
- 提供保证收益的策略或喊单。
- 作为实时行情终端使用。
- 代替完整的交易训练与风险教育。

明确边界，才能把工具用在真正有价值的地方：**更快找到知识，更准确地复盘自己的判断。**
